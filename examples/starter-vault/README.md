# Starter Vault

1. Change `site.baseUrl` and the site title in `.githubpage/site.json`.
2. Install and enable the Obsidian **GitHubPage** plugin once.
3. Clone this repository, open its root as an Obsidian Vault, and use **GitHubPage: Open website preview**.
4. In repository settings, select **GitHub Actions** as the Pages source and protect `main` with pull requests and the build check.

All Markdown is public by default. `draft: true` or `publish: false` removes a page from the built site, but not from Git history.
